# Vooya Lab Brand Assets

This directory owns shared identity originals, accepted vector marks, optimized
derivatives, briefs, and provenance. Follow `docs/visual-identity.md`.

- `vooya-lab-lovart-brief.md` is the first Lovart exploration brief.
- `provenance.template.json` is copied beside every retained generated asset.
- `lovart-generated/` contains traceable Lovart experiments. An experiment is
  not an accepted logo or production asset unless its provenance review says
  otherwise.
- Keep originals; generate derivatives into a sibling `derivatives/` directory.
- Do not use generated artwork as evidence of a live Vooya case.
